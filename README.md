# Portfolio

A modern, responsive portfolio website showcasing my projects, skills, and experience as a full-stack developer.

## Features

- **Modern Design**: Glassmorphism effects, smooth animations, and gradient backgrounds
- **Fully Responsive**: Works seamlessly on desktop, tablet, and mobile devices
- **Interactive UI**: 3D card effects, hover animations, and smooth scrolling
- **Single File**: Everything contained in one HTML file - no build process required

## Sections

- **Home**: Introduction and quick overview
- **About**: Background, approach, and what I do
- **Skills**: Technical skills organized by category
- **Projects**: Featured projects with live demos and GitHub links
- **Ongoing Project**: Current work and active development
- **Contact**: Ways to get in touch

## Tech Stack

- **React 18** (via CDN)
- **Vanilla CSS** with modern effects
- **No build tools required**

## Getting Started

Simply open `portfolio.html` in any modern web browser:

```bash
# Open directly in browser
open portfolio.html
```

Or use a local server:

```bash
# Python
python -m http.server 8000

# Node.js
npx serve
```

Then visit `http://localhost:8000`

## Deployment

This portfolio can be deployed to any static hosting service:

- **Vercel**: `vercel deploy`
- **Netlify**: Drag and drop to [netlify.com/drop](https://app.netlify.com/drop)
- **GitHub Pages**: Enable in repository settings
- **Cloudflare Pages**: Connect your GitHub repo

No environment variables or build configuration needed!

## Customization

To customize the portfolio:

1. Update personal information in the hero section
2. Modify the `skills` object with your technologies
3. Update the `projects` array with your work
4. Change the `currentWork` array for ongoing projects
5. Update contact links (email, GitHub, X/Twitter)
